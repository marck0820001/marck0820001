### 🗂️ Memory Systems for AI

One of the topics I'm particularly interested in is how AI systems can maintain useful information across multiple interactions.

I'm experimenting with concepts such as:

* **Short-term conversational memory**
* **Long-term persistent memory**
* Semantic memory
* Episodic memory
* Retrieval-based memory
* Knowledge graphs
* Vector-based memory

I'm also exploring the use of **Obsidian as a personal knowledge base**, connecting structured notes and knowledge with AI systems.

The idea is to investigate architectures where an AI agent can retrieve information from a personal knowledge repository and use it as contextual memory.

```text
        ↓

        ↓

        ↓

        ↓
AI Agent
```

### 🔎 Retrieval-Augmented Generation (RAG)

I'm studying RAG systems beyond the basic **retrieve → prompt → generate** pipeline.

Some of the components I'm exploring include:

* Document ingestion pipelines
* Chunking strategies
* Embedding models
* Vector databases
* Semantic search
* Hybrid search
* Metadata filtering
* Query transformation
* Context retrieval
* Reranking
* Prompt construction
* Response generation
* Evaluation of RAG pipelines

I'm particularly interested in understanding how each component affects the **quality, relevance, and reliability of the final response**.

---

### 🧬 Fine-Tuning & RAG Optimization

I'm also exploring how **fine-tuning and optimization techniques** can improve individual components of a RAG architecture.

Topics I'm studying include:

* Fine-tuning **embedding models** for domain-specific retrieval
* Improving semantic similarity between queries and documents
* Training or adapting **reranking models**
* Optimizing retrieval strategies
* Evaluating retrieval quality
* Improving context relevance
* Domain-specific AI systems
* Comparing base models vs. specialized models

Instead of treating RAG as a single system, I'm interested in understanding and improving each layer independently.

```text
User Query
    ↓
Query Processing
    ↓
Embedding Model
    ↓
Vector / Hybrid Search
    ↓
Candidate Documents
    ↓
Reranker
    ↓
Relevant Context
    ↓
LLM
    ↓
Generated Response
```
